# Shot van de Week – eredivisiebadminton.nl

Stemwidget en winnaarsoverzicht voor Shot van de Week. Gegevens komen uit de Google Sheet "Shot van de Week" (Apps Script web-app).

## Inbouwen in Squarespace (Code Block)

Stemmen:
```html
<div class="svdw" data-weergave="stemmen"></div>
<script src="https://studioloos.github.io/shot-van-de-week/svdw.js" defer></script>
```

Winnaars:
```html
<div class="svdw" data-weergave="winnaars"></div>
<script src="https://studioloos.github.io/shot-van-de-week/svdw.js" defer></script>
```

Foto's per ronde staan in `rondes/<nummer>/`, winnaarsafbeeldingen in `winnaars/`.
